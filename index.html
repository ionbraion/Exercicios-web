Este site está sendo criado com a finalizade de aprendizagem dos alunos de programação para a internet

A Internet é a infraestrutura global de redes de computadores interconectados que permite a troca de dados. Já a Web (World Wide Web) é um sistema de informação que roda sobre a Internet, permitindo o acesso a páginas e documentos interligados por hiperlinks através de navegadores.
